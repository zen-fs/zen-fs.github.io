Backends for cloud storage providers.

```sh
npm install @zenfs/cloud
```

<Version pkg="cloud" />

## Backends

| Backend       | Provider                |
| ------------- | ----------------------- |
| `Dropbox`     | Dropbox                 |
| `GoogleDrive` | Google Drive            |
| `S3Bucket`    | Amazon Web Services' S3 |

Each backend takes an authenticated client for its provider.
See the [reference](/cloud/reference/) for the exact options.
