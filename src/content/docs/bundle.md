---
title: '@zenfs/bundle'
description: A pre-built bundle of ZenFS and several backends, for use without a build step.
---

`@zenfs/bundle` packages `@zenfs/core` together with several backends into a single pre-built file,
for use without a bundler or build step.

```sh
npm install @zenfs/bundle
```

This is intended only for prototyping and should never be used in production.
